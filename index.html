PRIMEROS (First) y SIGUIENTES (Follow)

Los conjuntos PRIMEROS indican con qué símbolos puede comenzar una regla gramatical. Los SIGUIENTES muestran qué símbolos pueden venir después.

No TerminalPRIMEROS ( α )SIGUIENTES ( A )
programa{ var, si, mientras, escribir, leer, ID }{ EOF }
sentencia{ var, si, mientras, escribir, leer, ID }{ }, EOF }
declaracion{ var }{ var, si, mientras, escribir, leer, ID, } }
asignacion{ ID }{ var, si, mientras, escribir, leer, ID, } }
si_stmt{ si }{ var, si, mientras, escribir, leer, ID, }, EOF }
mientras_stmt{ mientras }{ var, si, mientras, escribir, leer, ID, }, EOF }
expresion{ ENTERO, DECIMAL, CADENA, BOOL, ID, ( }{ ;, ), comma, ==, !=, <, >, <=, >= }
termino{ ENTERO, DECIMAL, CADENA, BOOL, ID, ( }{ +, -, ;, ), comma, operadores_relacionales }
factor{ ENTERO, DECIMAL, CADENA, BOOL, ID, ( }{ *, /, %, +, -, ;, ), operadores_relacionales }

📐 Gramática BNF y Diagrama de Conway

La gramática formal en notación BNF (Backus-Naur Form) y los diagramas de Conway (railroad diagrams) que representan visualmente las reglas de producción de Flor.

Gramática BNF Completa — Flor
<programa> ::= { <sentencia> } EOF <sentencia> ::= <declaracion> | <asignacion> | <si> | <mientras> | <escribir> | <leer> <declaracion> ::= 'var' <ID> '=' <expresion> ';' <asignacion> ::= <ID> '=' <expresion> ';' <si> ::= 'si' '(' <condicion> ')' '{' { <sentencia> } '}' [ 'sino' '{' { <sentencia> } '}' ] <mientras> ::= 'mientras' '(' <condicion> ')' '{' { <sentencia> } '}' <escribir> ::= 'escribir' '(' <expresion> ')' ';' <leer> ::= 'leer' '(' <ID> ')' ';' <expresion> ::= <termino> { ('+' | '-') <termino> } <termino> ::= <factor> { ('*' | '/' | '%') <factor> } <factor> ::= ENTERO | DECIMAL | CADENA | BOOLEANO | ID | '(' <expresion> ')' <condicion> ::= <expresion> OP_REL <expresion> | <expresion> OP_LOG <expresion> | '!' <condicion> OP_REL ::= '==' | '!=' | '<' | '>' | '<=' | '>=' OP_LOG ::= '&&' | '||'
